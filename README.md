# Umit 17.x — настройка по Bluetooth

Страница: https://barsqwerty001-byte.github.io/umit-tuner-17/

- сила нажатия (порог клика) с живой шкалой и подбором по своим нажатиям;
- скорость, порог мелких движений, плавность, переворот осей;
- датчики: нажим, ноль датчика, поворот/кивок головы, скорость курсора, батарея, наклон платы.

Нужен Chrome (Android, Windows, Mac). iPhone не поддерживает Web Bluetooth.
Нажатие и датчик — прошивка 17.6+, движение на дашборде — 17.7+.
Изменения работают сразу; «Сохранить» оставляет их после перезагрузки.
